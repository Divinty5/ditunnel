# Переводы установщика

Русский, английский и испанский переводы поставляются с Inno Setup.

Упрощённый китайский: [перевод Zhenghan Yang (Kira) для Inno Setup 6.5.0+](https://github.com/kira-96/Inno-Setup-Chinese-Simplified-Translation), файл `ChineseSimplified.isl`. Копия лицензии MIT сохранена в `LICENSE-ChineseSimplified`.

Сообщения Di-Tunnel о восстановлении сети переведены отдельно в разделе `[CustomMessages]` файла `DiTunnel.iss`.
