# Di-Tunnel

Di-Tunnel — VPN-клиент с открытым исходным кодом для Windows, Android и Linux. Для подключения нужен собственный VPN-профиль или ссылка от провайдера. Серверы и подписки в комплект не входят.

![Логотип Di-Tunnel](icon.png)

## Возможности

- Подключение через Xray и AmneziaWG. Поддерживаются профили VLESS, VMess, Trojan, Shadowsocks и Hysteria 2. [Форматы и ограничения](docs/user-guide.md#протоколы-и-форматы).
- Импорт отдельных профилей и подписок из ссылок, буфера обмена или QR-кодов.
- Проверка серверов, выбор по задержке и переключение профиля из списка.
- Раздельное туннелирование по приложениям, доменам и IP-адресам с учётом особенностей платформы. [Раздельное туннелирование](docs/user-guide.md#раздельное-туннелирование).
- Восстановление VPN после потери сети, защита соединения и отчёты о сбоях. [Защита и диагностика](docs/user-guide.md#проверка-серверов-и-диагностика).

## Скачать

Скачайте пакет для своей системы и соседний файл с контрольной суммой SHA-256. Если в последнем выпуске нет пакета для вашей платформы, выберите последний стабильный выпуск, где он есть. [Последний общий релиз](https://github.com/Divinty5/ditunnel/releases/latest) · [Все выпуски](https://github.com/Divinty5/ditunnel/releases).

| Платформа | Минимальные требования | Файл |
| --- | --- | --- |
| Windows x64 | Windows 10 2004, сборка 19041 | `Di-Tunnel-<версия>-Setup-x64.exe` |
| Android ARM64 | Android 8.1 (API 27) | `Di-Tunnel-<версия>-arm64.apk` |
| Linux amd64 | Ubuntu 24.04 LTS | `Di-Tunnel-<версия>-linux-amd64.run` или `.deb` |

На Windows запустите установщик и подтвердите запрос UAC. При первом подключении отдельный сетевой модуль также может запросить права администратора. На Android разрешите установку APK из выбранного источника и подтвердите системный запрос на создание VPN. На Ubuntu запустите графический установщик `.run` или установите `.deb` и подтвердите запрос polkit. [Установка и проверка SHA-256](docs/installation.md).

## Быстрый старт

1. Откройте Di-Tunnel и нажмите **+**.
2. Импортируйте ссылку на профиль или подписку из буфера обмена, отсканируйте QR-код либо добавьте профиль вручную.
3. Откройте **Подписки и профили** и выберите сервер.
4. Нажмите **Подключить** на главном экране. Из списка можно сразу подключить или переключить VPN двойным либо долгим нажатием на нужный профиль.

Жёлтый индикатор означает подключение, восстановление или проверку связи, зелёный — подтверждённое подключение, красный — ошибку, фиолетовый — отключение. В списке активный профиль выделяется независимо от строки, выбранной для действий. [Подписки, профили и проверки](docs/user-guide.md#подписки-и-профили).

## Что нужно знать

- На Windows и Ubuntu встроенный kill switch блокирует прямой трафик при сбое туннеля, если защита включена. На Android соответствующую блокировку включает системная настройка **Блокировать соединения без VPN**. [Защита соединения](docs/user-guide.md#защита-соединения-и-восстановление).
- Windows-установщик выпускается без подписи Authenticode. Android-сборка предназначена для ARM64 и работает без Google Play Services. На Ubuntu нужны systemd, systemd-resolved и доступная связка ключей Secret Service. [Особенности установки](docs/installation.md).
- По умолчанию подписки обновляются через активный VPN. Прямое обновление можно включить в разделе **Настройки → Соединение**. [Обновление подписок](docs/user-guide.md#подписки-и-профили).
