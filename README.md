# Di-Tunnel

Di-Tunnel — VPN-клиент для Windows и Android на базе Xray-core. Приложение импортирует серверы и подписки, проверяет их доступность, переключает активный профиль и направляет трафик через системный VPN/TUN.

![Значок Di-Tunnel](icon.png)

## Поддерживаемые платформы

| Платформа | Минимальная версия | Релизный формат |
| --- | --- | --- |
| Windows x64 | Windows 10 2004 (build 19041) | `Di-Tunnel-<версия>-Setup-x64.exe` |
| Android ARM64 | Android 10 (API 29), включая проверенный HarmonyOS 2 | `Di-Tunnel-<версия>-arm64.apk` |

Android-сборка не зависит от Google Play Services. Сейчас выпускается только для `arm64-v8a`; ARM32 и универсальный APK не публикуются.

## Установка

Откройте [последний релиз](https://github.com/Divinty5/ditunnel/releases/latest), скачайте файл для своей платформы и опубликованную SHA-256 checksum.

На Windows запустите установщик и подтвердите UAC. В комплект уже входят .NET Runtime, Xray-core и Wintun. Пока установщик не подписан, Windows может показать предупреждение о неизвестном издателе.

На Android разрешите установку APK из выбранного источника. При первом подключении подтвердите системный запрос на создание VPN. Для гарантированной блокировки трафика вне туннеля включите для Di-Tunnel системные параметры **Постоянный VPN** и **Блокировать подключения без VPN**.

Проверка SHA-256 в PowerShell:

```powershell
Get-FileHash .\Di-Tunnel-<версия>-arm64.apk -Algorithm SHA256
```

## Быстрый старт

1. Нажмите **+**.
2. Импортируйте ссылку/подписку из буфера, QR-кода либо добавьте профиль вручную.
3. Откройте **Подписки и профили** и выберите сервер.
4. Нажмите **Подключить**.

Подписки можно обновлять вручную. Быстрая проверка использует TCP, а для Hysteria 2 — HTTP через временный Xray-туннель с повторной попыткой. Точная проверка выполняет HTTPS-запрос через профиль. Режим **Lowest** периодически выбирает доступный сервер с минимальной измеренной задержкой.

Подключение поддерживает Hysteria 2, VLESS поверх TCP/WebSocket/HTTPUpgrade, Trojan и Shadowsocks SIP002. VMess и произвольный Xray JSON можно импортировать и хранить, но подключение через них пока не реализовано.

## Хранение данных

На Windows профили хранятся в `%LOCALAPPDATA%\DiTunnel` и шифруются DPAPI текущего пользователя. На Android данные находятся во внутреннем каталоге приложения, защищены Android Keystore и исключены из резервного копирования. Удаление Android-приложения удаляет его локальные подписки и настройки.

## Защита соединения

Windows kill switch использует собственные правила Windows Filtering Platform для IPv4 и IPv6. Они сохраняются во время восстановления VPN и удаляются при штатном отключении.

На Android приложение следит за физической сетью через `ConnectivityManager`, сразу отмечает её потерю и восстанавливает туннель после появления подтверждённого подключения. Полный fail-closed обеспечивает системный Always-on VPN с блокировкой соединений без VPN.

При переключении сервера работающий VPN безопасно переподключается. Простое открытие другой подписки не меняет активный профиль.

## Раздельное туннелирование

Доступны режимы **Всё через VPN**, **Обход выбранных** и **Только выбранные через VPN**. Домены и IPv4-адреса вводятся по одному в строке; URL автоматически приводятся к имени хоста. На Android дополнительно можно выбрать несколько приложений. Windows-маршрутизация по приложениям пока не реализована.

## DNS и проверка утечек

Для Windows в изолированной VM подтверждены VPN-выход IPv4/IPv6, отсутствие DNS хоста и блокировка прямого трафика при потере сети. На Android ARM64 подтверждены VPN-адрес и только DNS-резолверы Cloudflare в стране VPN-сервера. Результат зависит от профиля, сервера, ОС и выбранных правил маршрутизации.

Подробнее: [Windows TUN/DNS validation](docs/windows-tun-validation.md) и [Android release validation](docs/android-release-validation.md).

## Восстановление Windows

Если приложение сообщает, что очистка сети не завершена, закройте Di-Tunnel и запустите от администратора:

```powershell
.\scripts\Repair-DiTunnelNetwork.ps1
```

Скрипт удаляет только маршруты, DNS-политику и WFP-объекты Di-Tunnel и отказывается работать при активном туннеле.

## Известные ограничения

- Windows installer пока не подписан кодовой подписью.
- Android-релиз выпускается только для ARM64 и устанавливается вручную.
- Нет рабочего подключения VMess, произвольного Xray JSON и AmneziaWG.
- Hysteria 2 использует UDP/QUIC, поэтому проверяется медленнее и сильнее зависит от качества сети.
- Windows UI пока работает с повышенными правами; отдельная служба запланирована на будущее.

## Разработка

Требуются .NET SDK `10.0.302+` и соответствующие workloads:

```powershell
dotnet restore
dotnet test DiTunnel.sln
dotnet build src\DiTunnel.Desktop\DiTunnel.Desktop.csproj -c Release
dotnet publish src\DiTunnel.Android\DiTunnel.Android.csproj -c Release -r android-arm64
```

## Сторонние компоненты

Windows распространяет закреплённый Xray-core `v26.3.27` и Wintun. Android использует закреплённый libXray `v26.7.28`. Версии, источники и SHA-256 записаны в `eng/`. Xray-core/libXray распространяются по MPL-2.0; сторонние уведомления включаются в релизные материалы. Собственный код Di-Tunnel распространяется по [лицензии MIT](LICENSE).
