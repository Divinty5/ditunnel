# Di-Tunnel

Di-Tunnel — VPN-клиент для **Windows**. Он подключает весь системный трафик через TUN, работает с подписками и отдельными прокси-профилями на базе Xray-core.

> Сейчас доступна только Windows 10 версии 2004 и новее. Версии для Android и Linux пока не выпущены.

![Di-Tunnel icon](icon.png)

## Установка

1. Откройте страницу [последнего релиза](https://github.com/Divinty5/ditunnel/releases/latest).
2. Скачайте `Di-Tunnel-0.3.4-Setup-x64.exe` и рядом лежащий файл `.sha256`.
3. При желании сверьте SHA-256 установщика:

   ```powershell
   Get-FileHash .\Di-Tunnel-0.3.4-Setup-x64.exe -Algorithm SHA256
   ```

4. Запустите установщик и подтвердите запрос Windows UAC.
5. Откройте Di-Tunnel через меню «Пуск» или ярлык на рабочем столе.

Установщик содержит .NET Runtime, Xray-core и Wintun, поэтому отдельно устанавливать .NET SDK, Xray или драйвер TUN не нужно. Установщик пока не подписан кодовой подписью, поэтому Windows может показать предупреждение об издателе.

Для работы TUN приложение запрашивает права администратора при запуске. Перед удалением выйдите из Di-Tunnel через иконку в трее. Профили и настройки остаются в `%LOCALAPPDATA%\DiTunnel` и сохраняются после переустановки.

## Начало работы

1. Нажмите **+** и импортируйте ссылку, текст подписки или данные из буфера обмена.
2. Выберите профиль в разделе **Подписки и профили**.
3. Нажмите **Подключить** на главном экране.
4. Проверьте состояние подключения и задержку.

Поддерживаются HTTPS- и Base64-подписки, VLESS, VMess, Trojan, Shadowsocks SIP002, Hysteria 2 и Xray JSON. Сохранённые профили шифруются Windows DPAPI для текущего пользователя.

## Возможности

- Подключение системного трафика через Xray TUN.
- Подписки, профили и автоматическое переподключение при смене сервера.
- Проверка доступности и задержки серверов через прокси.
- Адаптивный список серверов; результаты проверки сортируются по задержке.
- Автоматический выбор доступного сервера с наименьшей задержкой.
- Раздельное туннелирование по доменам с автоматическим обновлением IP-адресов во время подключения.
- Русский и английский интерфейсы, системный трей, темы и экспорт обезличенных сетевых журналов.
- Флаги серверов на основе локальной базы Xray GeoIP.

## Раздельное туннелирование

В настройках есть три режима:

- **Всё через VPN** — обычный режим.
- **Обход выбранных** — указанные домены идут напрямую, вне VPN.
- **Только выбранные через VPN** — через VPN идут только указанные домены.

Указывайте один домен в строке. Можно вставить URL или путь: `ifconfig.me/ip` автоматически станет `ifconfig.me`. Правила сохраняются при выходе из настроек. Пока подключение активно, Di-Tunnel примерно раз в 45 секунд обновляет маршруты указанных доменов.

Правило относится к одному домену. Крупные сервисы, включая YouTube, обычно используют несколько доменов и CDN, поэтому одного `youtube.com` может быть недостаточно. Раздельное туннелирование по приложениям ещё не реализовано.

## Ограничения предварительной версии

- Нет kill switch.
- Не завершены проверки утечек DNS и IPv6, сна/пробуждения и смены сети.
- Нет автоматического восстановления после потери сети.
- Поддержка Android и Linux планируется позднее.

Если приложение сообщило о незавершённой очистке сети, дождитесь завершения сетевого процесса и запустите от администратора `scripts\Repair-DiTunnelNetwork.ps1`. Скрипт удаляет только состояние, созданное Di-Tunnel, и не выполняется при активном туннеле.

Для разработки нужны Visual Studio 2026 с workload .NET desktop или .NET SDK 10.0.302+:

```powershell
dotnet restore
dotnet build
.\scripts\Start-DiTunnel.ps1
```

Установщик можно собрать с Inno Setup 6 или 7:

```powershell
.\scripts\Build-WindowsInstaller.ps1
```
