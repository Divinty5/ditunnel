# Linux process lookup в Xray

Linux runtime собирается из того же закреплённого Xray 26.3.27 (`v1.260327.0`), с проверкой Go module sum и SHA-256 изменяемых исходников. Официальные release geoip/geosite и лицензия сохраняются. Исправление применяется только к Linux runtime; Windows и Android runtime не меняются.

`process_lookup.py` исправляет формат адресов `/proc/net/*6`: переставляются байты каждого 32-битного слова, а не всего IPv6 адреса. Адрес маршрутизации копируется перед преобразованием. Для UDP поддерживается сокет с неопределённым локальным адресом; точное совпадение имеет приоритет. При неоднозначном SO_REUSEPORT владельце выбирается ошибка вместо произвольного процесса. Добавлен поиск IPv4 через dual-stack IPv6 socket. В matcher используется `JoinHostPort`, чтобы IPv6 источник передавался со скобками и принимался парсером.

`process_lookup_test.go` проверяет IPv6, сохранность адреса, wildcard и неоднозначность, настоящие локальные TCP/UDP sockets обеих семейств и dual-stack. `scripts/Prepare-LinuxRuntime.py --test` запускает их на Linux вместе с `process_routing_test.go` и существующими тестами `common/net` и `app/router`, затем собирает runtime. Изменённые MPL-2.0 исходники и описание модификации включаются в `xray-process-source` рядом с runtime, Версия исправления и SHA-256 бинарника записываются в `XRAY-SOURCE.json`; служба проверяет соответствие перед объявлением поддержки РТ и применением правил процессов.

Маршрутизация по приложениям основана на фактическом executable процесса. Общие сокеты нескольких процессов, завершение владельца до lookup, другие network namespaces и sandbox launchers требуют отдельных проверок. Системный DNS остаётся общим и принудительно идёт через VPN.
