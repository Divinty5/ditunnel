# Di-Tunnel 0.6.0 для Linux

Подготовлен первый установочный пакет для Ubuntu 24.04 LTS amd64. Версии Windows и Android сохранены на 0.5.19. Публикация релиза и загрузка на компьютер института выполняются отдельно.

- Добавлены общий Avalonia UI, защищённые профили через Secret Service, системная служба с polkit и self-contained .NET.
- Реализованы TUN IPv4/IPv6, DNS через systemd-resolved, проверка серверов, оба режима РТ по доменам/IP и приложениям.
- Добавлены nftables kill switch, LAN-исключение и сохранение блокировки после аварии ядра/клиента/службы.
- Подготовлены `.deb`, SHA-256, ярлык меню приложений, пользовательский XDG autostart и установка обновлений через apt/polkit.
- Добавлено административное восстановление сети перед обновлением/удалением. При ошибке удаления защита и runtime сохраняются. Профили и ключи пользователя не удаляются даже при purge.

Файлы: `Di-Tunnel-0.6.0-linux-amd64.deb` и `Di-Tunnel-0.6.0-linux-amd64.deb.sha256`. [Установка и сборка](linux-installation.md), [проверки VM](linux-vm-testing.md).

Границы первого Linux-релиза: смена профиля/сетевых настроек под KS требует явного отключения; бесшовный reconnect и защита после reboot не реализованы. Трей в GNOME не заявлен — окно всегда можно вернуть из панели задач. Реальный AWG handshake, остальные варианты транспорта, suspend/uplink switch, публичный IPv6 и институтская Ubuntu требуют отдельной матрицы. Полный паритет с Windows/Android не заявлен.
