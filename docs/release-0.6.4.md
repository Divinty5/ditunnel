# Di-Tunnel 0.6.4 — Windows, Android и Linux

Версии трёх платформ синхронизированы: 0.6.4; Android versionCode — 60004.

В общий релиз также вошли подготовленные изменения [0.6.2](release-0.6.2.md): режим «Использовать только IPv4», сворачиваемые настройки, исправления доменных зон `ru`/`рф`, заголовков окон, возврата из трея и Android-текста о защите.

- В Windows добавлен собственный компонент `DiTunnel.ShellIcon.dll` для полного цветного логотипа работающего приложения на панели задач, включая закреплённую кнопку. Кнопка не удаляется и не добавляется повторно. Windhawk, отдельная служба и автозапуск не нужны. Компонент загружается в Проводник и ограничивает смену источника значка группой Di-Tunnel. При закрытии клиента снимаются перехваты; аварийное завершение отслеживает таймер владельца.
- Старый способ перезаписи ярлыков при каждой смене цвета удалён. Предусмотрено однократное восстановление собственных ярлыков со старым `Icons/taskbar*.ico`; чужие и пользовательские значки сохраняются.
- В подписках и профилях на всех платформах сохранена прокрутка списка во время проверки серверов. На время проверки заблокирован выбор строк; список и ScrollViewer остаются активными. После отмены или завершения проверки выбор снова доступен.
- Сохранено минималистичное оформление настроек из 0.6.3.

Пользователь подтвердил мгновенную смену полного закреплённого логотипа по F1/F2/F3 в диагностическом окне с кодом компонента из приложения, без Windhawk и без исчезновения кнопки, на панели ExplorerPatcher и на штатной панели Windows 11. После проверки восстановлена вертикальная панель ExplorerPatcher. Затем пользователь установил новую сборку на рабочем компьютере и подтвердил изменение значка без предупреждений Касперского. Это результат для проверенной конфигурации, а не гарантия для всех версий антивируса. Путь классической панели Windows 10 реализован, но визуально на Windows 10 не проверен.

Для штатной панели при первом запуске после обновления Windows могут понадобиться публичные символы с `msdl.microsoft.com`; затем используется кэш, привязанный к SHA256 образа панели. Если нужные функции не найдены или версия не совпадает, перехваты не устанавливаются. Для ExplorerPatcher используются экспорты, загрузка символов не нужна. Это реализация на внутренних функциях Windows: совместимость с будущими обновлениями и всеми конфигурациями защиты не гарантируется. [Подробности реализации и диагностики](windows-taskbar-icon-investigation.md).

Проверены 127 тестов приложения, в том числе формат IPC и отказ при несовпадающих PE/RVA. Нативные тесты прошли 100 циклов двух путей отрисовки без утечки дескрипторов: изоляция чужих/незапущенных групп, снятие перехватов, потеря владельца и частичная ошибка установки. Нативные тесты работают в собственном процессе без Проводника. В установщик включена только основная DLL, без тестовых экспортов, с уведомлениями MinHook BSD в `Licenses/ShellIcon`.

Windows UI smoke проверил минималистичные настройки, прокрутку и защиту выбора во время синтетических проверок для трёх значений платформы, цвета нативного значка, сохранение HWND/размеров/фокуса и миграцию старых ярлыков с сохранением чужих и пользовательских ресурсов. Проверка HICON сама по себе не доказывает правильное изображение панели; визуальное подтверждение указано отдельно выше.

Windows и Linux Release собраны без ошибок и предупреждений. Android ARM64 собран с прежними 33 предупреждениями, подпись, выравнивание и метаданные APK (0.6.4/60004, minSdk 27, ARM64) проверены. Linux `.deb` собирается и проверяется в GitHub Actions на Ubuntu 24.04 из коммита релиза. Автоматические проверки использовали синтетические состояния и профили; маршруты, DNS, адаптеры и WFP основной системы не изменялись.

| Платформа | Пакет |
| --- | --- |
| Windows x64 | `Di-Tunnel-0.6.4-Setup-x64.exe` |
| Android ARM64 | `Di-Tunnel-0.6.4-arm64.apk` |
| Linux amd64 | `Di-Tunnel-0.6.4-linux-amd64.deb` |

Каждый опубликованный пакет сопровождается файлом `.sha256`. Прежний Windows-установщик 0.6.4 с SHA256 `8d3b1df067ba58bcae8a3bfe893304c12602fdbf292ce9ddc24824380cc5a0b4` собственного компонента не содержал и этот дефект не исправлял.

Для ручной проверки автономного варианта создана также копия нового установщика `Di-Tunnel-0.6.4-Setup-x64-independent.exe` с отдельным checksum. Перед обновлением следует штатно выйти из старого приложения через трей и дождаться его закрытия. Установщик здесь не запускался: его сетевое восстановление меняет системное состояние.

SHA256 нового Windows-установщика (76 661 282 байта): `02a48a78dcb3f2b83e253d88d1f5e6ec3ea891df29557d62c4886f64240eeb12`.
