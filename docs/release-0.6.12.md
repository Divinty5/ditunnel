# Di-Tunnel 0.6.12 для Windows и Android

В Windows исправлено закрытие приложения после сигнала установщика, когда обновление запускается из настроек. Ручная и автоматическая проверки не запускаются одновременно. При удалении собственного правила NRPT Di-Tunnel ждёт обновления действующей политики Windows. Стороннее общее правило сохраняется и отображается как причина отказа.

В Android исправлен цвет задержки на главном экране. В обеих сборках копируемый отчёт текущей ошибки не включает прежнюю успешную проверку. Короткая ошибка показывает этап, например `DNS сервера · Тайм-аут`, `Handshake AWG · Тайм-аут` или `Ошибка TLS`.

Для перехода с установленной Windows 0.6.11 включите автоматическую установку, выйдите из Di-Tunnel через трей и запустите его снова. Подтвердите запрос UAC, если он появится. Путь запуска через настройки исправлен в клиенте 0.6.12. Проверка полноценного перехода через UAC остаётся ручной.

В сообщении о падении Android 0.6.10 Build ID совпал с библиотекой из опубликованного APK. Адрес `0x6a5e0` соответствует `EmbeddedAssemblies::open_from_bundles` в Mono и совпадает с инструкцией в известном отчёте о гонке загрузчика. Исправление падения на устройстве требует отдельного подтверждения. [Отчёт .NET Android](https://github.com/dotnet/android/issues/13194).
