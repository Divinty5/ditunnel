# Di-Tunnel 0.6.12 для Windows, Android и Linux

В Windows исправлено закрытие приложения после сигнала установщика, когда обновление запускается из настроек. Ручная и автоматическая проверки не запускаются одновременно. При удалении собственного правила NRPT Di-Tunnel ждёт обновления действующей политики Windows. Стороннее общее правило сохраняется и отображается как причина отказа.

В Android исправлен цвет задержки на главном экране. На всех трёх платформах копируемый отчёт текущей ошибки содержит данные этой же попытки. Короткая ошибка показывает этап, например `DNS сервера · Тайм-аут`, `Handshake AWG · Тайм-аут` на Android или `Ошибка TLS`.

Автоматическое обновление Windows с 0.6.11 до 0.6.12 подтверждено с запросом UAC. Обновление Android с 0.6.10 до 0.6.12 также подтверждено на устройстве.

Для Ubuntu 24.04 amd64 добавлен пакет `.deb`. Точная проверка различает DNS сервера, запуск AmneziaWG, запуск Xray и проверку контрольного сайта. В пакете используется Xray 26.3.27 с поддержкой Linux-правил по процессам. [Установка и обновление](linux-installation.md).

В сообщении о падении Android 0.6.10 Build ID совпал с библиотекой из опубликованного APK. Адрес `0x6a5e0` соответствует `EmbeddedAssemblies::open_from_bundles` в Mono и совпадает с инструкцией в известном отчёте о гонке загрузчика. Исправление падения на устройстве требует отдельного подтверждения. [Отчёт .NET Android](https://github.com/dotnet/android/issues/13194).
