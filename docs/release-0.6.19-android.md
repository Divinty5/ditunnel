# Di-Tunnel 0.6.19 — Android

Этот выпуск заменён версией 0.6.20. [Актуальный выпуск Android](release-0.6.20-android.md).

## Изменения

- Восстановлена адаптивная раскладка в меню «Подписки и профили». На широком экране карточки размещаются рядом, а на узком — в одной прокручиваемой колонке. При изменении ширины выбранный профиль сохраняется.

## Пакет

Пакет `Di-Tunnel-0.6.19-arm64.apk` предназначался для Android 8.1 (API 27) и новее, ARM64, versionCode 60023.
