# Установка и обновление Di-Tunnel

Скачайте пакет и его файл `.sha256` из одного выпуска. Если в последнем выпуске нет пакета для вашей платформы, возьмите пакет из последнего стабильного выпуска, где он есть. [Последний релиз](https://github.com/Divinty5/ditunnel/releases/latest) · [Все выпуски](https://github.com/Divinty5/ditunnel/releases).

## Проверка файла

В Windows сравните вывод PowerShell с суммой в файле `.sha256`. В примерах указан выпуск 0.6.18. Подставьте точное имя скачанного пакета. Для APK можно выполнить ту же команду, указав имя APK.

```powershell
Get-FileHash -LiteralPath '.\Di-Tunnel-0.6.18-Setup-x64.exe' -Algorithm SHA256
```

На Ubuntu выполните команду в каталоге, где находятся оба файла. Для графического пакета замените `.deb` на `.run`.

```bash
sha256sum -c Di-Tunnel-0.6.18-linux-amd64.deb.sha256
```

## Windows x64

Поддерживается Windows 10 версии 2004 (сборка 19041) и новее. Запустите `Di-Tunnel-<версия>-Setup-x64.exe` и подтвердите UAC. Установщик поставляется без подписи Authenticode, поэтому Windows может показать неизвестного издателя. .NET, Xray-core, AmneziaWG и Wintun входят в комплект.

Основной интерфейс работает с обычными правами. Для подключения и некоторых проверок Windows запускает отдельный сетевой модуль, которому нужны повышенные права. Язык приложения выбирается в разделе **Настройки → Интерфейс**. Доступны русский, английский, испанский и упрощённый китайский.

## Android ARM64

Поддерживается Android 8.1 (API 27) и новее. Откройте `Di-Tunnel-<версия>-arm64.apk` и при необходимости разрешите установку из выбранного источника. При первом подключении подтвердите создание VPN. Google Play Services не требуются. Выпуск содержит APK для arm64-v8a. [Выпуски Di-Tunnel](https://github.com/Divinty5/ditunnel/releases).

Сохраняйте установленное приложение при обновлении APK с тем же сертификатом. Если Android отклоняет обновление из-за несовпадения подписей, проверьте источник текущей сборки и сохраните ссылки на подписки и профили перед возможным удалением. Удаление приложения очищает локальные данные. [Управление VPN на Android](android-controls-and-protocols.md).

## Ubuntu 24.04 amd64

Доступны графический установщик `.run` и пакет `.deb`. Графический установщик содержит тот же пакет. Для работы VPN нужны systemd, systemd-resolved и разблокированная связка ключей Secret Service. Сетевые операции требуют разрешения polkit. [Установка, обновление и удаление Ubuntu](linux-installation.md).

## Обновление приложения

Di-Tunnel ищет стабильный выпуск с пакетом и отдельным `.sha256` для текущей платформы. Для Windows используется `.exe`, для Android — APK с релизной подписью, для Ubuntu — `.deb`. В **Настройки → Обновления** можно установить найденную версию вручную или включить автоматическую установку. Кнопка **Позже** откладывает предложение до следующего запуска.

Перед установкой Di-Tunnel сверяет SHA-256 и штатно отключает VPN. Windows и Ubuntu перезапускают приложение после успешной установки. Windows может показать UAC, Ubuntu — запрос polkit. На Android установку нужно подтвердить в системном диалоге.
