# Di-Tunnel 0.6.10

Общий выпуск от 13 ноября 2026 для Windows x64, Android ARM64 и Ubuntu 24.04 amd64. [Скачать с GitHub](https://github.com/Divinty5/ditunnel/releases/tag/v0.6.10).

## Что изменилось

- Расширен импорт AmneziaWG 2.0 и 3.1, включая варианты `random_trailers` и `disable_cookies`. IP-адреса скрыты в названиях карточек AmneziaWG. [Поля и форматы импорта](amneziawg-integration.md).
- Точная проверка Android повторяется при временном тайм-ауте. После отмены проверки или подключения кнопки проверки снова доступны. При повторном сбое HTTPS активного туннеля Di-Tunnel пытается восстановить соединение. В режиме Lowest приложение может переключиться на проверенный сервер той же подписки.
- В Linux исправлены ожидание готовности туннеля и восстановление маршрутов. Обновление в приложении использует `apt` и перезапускает Di-Tunnel после успешной установки. Если обновление из старой версии завершается преждевременно, установите новый пакет вручную. [Инструкция для Ubuntu](linux-installation.md).
- В Windows обновление проходит без страниц мастера. Для первой установки доступны четыре языка, фиолетовые кнопки и флажки, а создание ярлыка выбрано по умолчанию. При первом запуске окно занимает правую половину рабочей области, при следующих восстанавливает размер, положение и режим.

## Совместимость

На Windows и Linux используется Xray 26.3.27, на Android — libXray 26.7.28. Переход на 26.11.9 отложен из-за несовместимости с публичными VLESS и Trojan без защиты транспорта, которые принимает текущее ядро Windows и Linux. Ядро AmneziaWG закреплено отдельно. Android APK имеет versionCode 60010 и требует Android 8.1 (API 27) на ARM64. [Проверка транспорта в Xray 26.11.9](https://github.com/XTLS/Xray-core/blob/v26.11.9/infra/conf/xray.go#L238-L268), [матрица Android](android-release-validation.md).

## Проверки перед выпуском

- Пользователь проверил работу сборок Windows и Android. У APK сверены подпись, метаданные, архитектура и выравнивание. Android 8.1 проверен по метаданным APK, запуск этого выпуска на API 27 остаётся отдельной проверкой.
- С текущими ядрами пройдены 686 тестов локального набора. В Ubuntu 24.04 VM прошли установка `.deb` через `apt`, запуск службы, TCP и UDP через TUN по IPv4 и IPv6, восстановление DNS и маршрутов после отказа. Для AmneziaWG проверены запуск и очистка локального туннеля. Внешний AWG handshake в этом прогоне не проверялся.
- Для каждого пакета опубликован соседний `.sha256`. [Порядок сборки и проверки](build-and-release.md).
