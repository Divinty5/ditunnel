# Di-Tunnel 0.6.11 для Windows

Выпуск снят с публикации после сообщения о сбое передачи управления от Di-Tunnel 0.6.10 установщику. Публичным остаётся [общий релиз 0.6.10](release-0.6.10.md).

В Windows x64 обновлён Xray-core с 26.3.27 до 26.6.27.

Xray 26.6.27 принимает прежние конфигурации VLESS и Trojan без защиты транспорта. В Xray 26.11.9 публичные профили такого вида отклоняются. Xray 26.6.27 отмечен разработчиками Xray как предварительный выпуск. [Xray 26.6.27](https://github.com/XTLS/Xray-core/releases/tag/v26.6.27), [проверка транспорта в Xray 26.11.9](https://github.com/XTLS/Xray-core/blob/v26.11.9/infra/conf/xray.go#L238-L268).

Перед выпуском пройдены 685 тестов .NET и тесты моста AmneziaWG. Проверены передача HTTP через локальные VLESS и VMess, авторизация SOCKS, DNS и маршрутизация по процессам. Переход с установленной 0.6.10 через интерфейс Windows остаётся ручной проверкой.

При запуске проверки из настроек 0.6.10 область навигации ошибочно использовалась как главное окно. Установщик посылал сигнал готовности и продолжал ждать выхода Di-Tunnel. Исправленный клиент находит главное окно и завершает приложение после сигнала. Пока выполняется одна проверка или установка, повторный запуск отклоняется. Проверка ручного обновления из настроек требует сборки с исправленным клиентом.
