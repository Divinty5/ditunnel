# Di-Tunnel 0.6.1 — Windows, Android и Linux

Общий стабильный релиз: версии всех платформ синхронизированы на 0.6.1. Android versionCode — 60001; минимальная версия Android остаётся API 27 (Android 8.1).

- Подсветка туннеля внутри значка окна в Windows и Linux соответствует состоянию VPN: зелёная — подключён, красная — ошибка, фиолетовая — отключён или подключается/восстанавливается. В Windows синхронизируется также значок трея. В Linux отображение значка окна на панели задач зависит от рабочего окружения.
- В раздельном туннелировании можно вводить кириллические домены, включая `рф` и `пример.рф`. В настройках они остаются читаемыми, а при маршрутизации преобразуются в Punycode. В режиме «Обход выбранных» строки `ru` и `рф` охватывают соответствующие доменные зоны и их поддомены.
- В релиз входят ранее подготовленные обмен профилями AmneziaWG через конфигурационные файлы, ссылки и QR-коды, а также Linux-пакет с собственным .NET, Xray и userspace AmneziaWG.

## Пакеты и автообновление

| Платформа | Пакет |
| --- | --- |
| Windows 10/11 x64 | `Di-Tunnel-0.6.1-Setup-x64.exe` |
| Android ARM64 | `Di-Tunnel-0.6.1-arm64.apk` |
| Ubuntu 24.04 LTS amd64 | `Di-Tunnel-0.6.1-linux-amd64.deb` |

Рядом с каждым пакетом опубликован одноимённый файл `.sha256`. Имена совместимы с проверкой обновлений Di-Tunnel; релиз имеет тег `v0.6.1`.

Linux-пакет предназначен для Ubuntu 24.04 amd64 с systemd, systemd-resolved и Secret Service. Установка и обновление: [инструкция Linux](linux-installation.md). Границы сетевой поддержки: [проверки VM](linux-vm-testing.md). Проверки сборки и пакетов не заменяют проверку VPN на конкретном устройстве.
