# Di-Tunnel 0.6.7 — тестовая сборка Windows

Локальная тестовая сборка от 30 октября 2026 года для Windows x64, начиная с Windows 10 build 19041. Стабильный релиз не опубликован. Версии Android 0.6.4 и Linux 0.6.6 не изменены.

## Изменение

При импорте и обновлении HTTPS-подписок Di-Tunnel отправляет User-Agent со своим именем и указанием совместимости с текстовым форматом v2rayN, а также Accept: text/plain. Заголовки сохраняются при разрешённых HTTPS-перенаправлениях. Это исправляет запрос без User-Agent, на который VLESS VPN Keys отвечал HTTP 500. Предел размера подписки, проверка сертификатов и запрет перенаправления на HTTP сохранены.

## Установка и проверка

1. Отключить VPN и выйти из Di-Tunnel через трей.
2. Запустить `Di-Tunnel-0.6.7-Setup-x64.exe` и подтвердить запрос установщика. Это обновление обычной установки Di-Tunnel; отдельный тестовый экземпляр не создаётся.
3. Проверить номер 0.6.7 в настройках приложения.
4. Добавить HTTPS-ссылку подписки через буфер обмена либо обновить уже добавленную подписку.
5. Убедиться, что появились настоящие серверы, выбрать сервер, выполнить проверку и попробовать подключиться.

Если вместо серверов сервис прислал записи о неактивной подписке или лимите устройств, обновление клиента не снимает это ограничение: нужно проверить состояние подписки у провайдера. Такие служебные VLESS-заглушки пока могут импортироваться как обычные профили. Успешный импорт сам по себе не подтверждает работоспособность VPN.

Для обратной связи достаточно версии Windows, текста ошибки и этапа сбоя: импорт, обновление, проверка или подключение. Не включать полную ссылку подписки, UUID и другие ключи в общедоступные отчёты.

## Файлы

- `artifacts/installer/Di-Tunnel-0.6.7-Setup-x64.exe` — установщик с .NET, Xray, AmneziaWG и Wintun.
- `artifacts/installer/Di-Tunnel-0.6.7-Setup-x64.exe.sha256` — контрольная сумма установщика.

Проверка полученного файла в PowerShell:

```powershell
Get-FileHash .\Di-Tunnel-0.6.7-Setup-x64.exe -Algorithm SHA256
```

Проверка реального подключения с этой подпиской на компьютере получателя остаётся задачей тестирования.

## Результаты проверки сборки

- Release publish Windows x64 с собственным .NET завершён успешно; версия приложения — 0.6.7.0.
- Core: 159 тестов пройдено. App: 138 тестов пройдено; проверка реестра выполнена в изолированном временном ключе тестов.
- Проверены обязательные файлы комплекта, архитектура x64 исполняемых файлов и нативных библиотек, наличие исправления импортёра в опубликованной сборке и SHA-256 AmneziaWG.
- Установщик скомпилирован Inno Setup; размер — 76 714 810 байт. SHA-256: `bd3b8a414c56910451203043e183dadf6dfd0886f5058551510b7c299f01750e`.
- При сборке NuGet сообщил NU1900: источник сведений об уязвимостях был недоступен. Это не помешало сборке; проверка уязвимостей зависимостей в этом прогоне не подтверждена.
- Установка на рабочий компьютер и реальное VPN-подключение в этот прогон не входили. Настройки сети и действующие профили основной системы не изменялись.
- После передачи установщика пользователь проверил сборку на своём рабочем ПК: подписка импортируется, но сервис по-прежнему возвращает служебную запись «Подиска не активна.». Работоспособность VPN с этой подпиской не подтверждена; ожидается ответ поддержки сервиса.
