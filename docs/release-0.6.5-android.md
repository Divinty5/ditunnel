# Android 0.6.5

Подготовлена отдельная Android-версия 0.6.5, versionCode 60005. Минимум Android 8.1 (API 27), архитектура ARM64. Версии и механизм проверки Windows/Linux не изменены. Публикация релиза выполняется отдельно.

## Проверки

Быстрая проверка TCP подтверждает только доступность адреса и порта сервера. Она не проверяет ключи, авторизацию и передачу данных; это явно указано в результате. Режим lowest не выбирает профиль по одному TCP-ответу.

Точная проверка запускает отдельный Xray для каждого профиля и выполняет HTTPS через SOCKS этого профиля. Ошибка одного профиля не уничтожает результаты остальных. Проверки выполняются последовательно в изолированном процессе Android; это может занять больше времени, чем прежняя пакетная проверка. Для AmneziaWG HTTPS выполняется через отдельный SOCKS-мост, без замены активного VPN.

Основной адрес — `https://1.1.1.1/cdn-cgi/trace` (тот же, что в текущей IPv4 HTTPS-проверке Windows/Linux), резервный — `https://www.gstatic.com/generate_204`. Ожидаются соответственно HTTP 200 и 204; перенаправления не принимаются. Пять секунд на каждый запрос позволяют выполнить резервную проверку после тайм-аута основного адреса. Проверка по IP не требует DNS контрольного адреса, резервный адрес дополнительно проверяет разрешение имени.

После запуска TUN выполняется контрольный запрос с явной привязкой к Android VPN Network, без выхода через физическую сеть. Последующие проверки активного соединения и виджеты используют эти же адреса. Запущенный TUN отображается отдельно от подтверждённого HTTPS. Отказ обоих адресов означает, что проверка не подтверждена: туннель сохраняется, предупреждение можно скопировать. Такие ошибки не запускают автоматическое переключение и не делают профиль кандидатом для массового удаления.

Отключённый клиент или истёкшая подписка могут выглядеть как обычный тайм-аут. Сообщение об истечении подписки из сетевой ошибки не выводится.

## Диагностика

Кнопка копирования на главном экране доступна для ошибок подключения и результатов Android-проверки. В текст включены метод, этап, категория ошибки, длительность, версия клиента и результаты основного/резервного запросов. Для пакетной проверки выбирается нужный профиль; копируется его последний результат. Данные сохраняются в памяти отдельно для каждого профиля, в том числе при переключении групп.

Категории: тайм-аут, DNS, TLS, соединение, контрольный сервис, конфигурация и внутренняя ошибка. Этапы отличают разрешение адреса сервера, TCP-подключение, запуск Xray, TLS и HTTPS. Нативная библиотека не всегда раскрывает причину отказа: если она неизвестна, более точный диагноз не придумывается. Содержимое профилей, серверные адреса, ключи, пароли и исходные сообщения исключений в диагностические поля не добавляются.

## Проверка на тестовом Android-устройстве

Автоматические тесты проверяют резервирование URL, DNS/TLS/тайм-ауты, отмену, изоляцию результатов, отсутствие секретов, недопустимость вывода об истечении подписки и поведение интерфейса. Они не заменяют проверку libXray, AmneziaWG и Android Network на устройстве.

Перед публикацией проверить:

1. Рабочий Xray-профиль: быстрая проверка показывает TCP без подтверждения профиля, точная — HTTPS; после подключения подтверждается HTTPS через TUN.
2. Отключённый клиент на доступном сервере: TCP может отвечать, HTTPS не подтверждается; сообщения «Подписка истекла» нет.
3. Недоступный основной контрольный адрес: резервный подтверждает HTTPS. Отказ обоих адресов сохраняет TUN, показывает предупреждение и позволяет скопировать причину.
4. Неверные DNS, порт, TLS и конфигурация одного профиля: показана известная причина, результаты остальных остаются доступны.
5. AmneziaWG, UDP/QUIC-профили, IPv6-only профиль, отмена во время проверки, повторное подключение, Always-on, правила приложений и крупные виджеты.
6. В копируемом тексте есть версия 0.6.5, метод, этап и длительность; отсутствуют реквизиты доступа. После восстановления контрольного сайта предупреждение снимается очередной проверкой.
