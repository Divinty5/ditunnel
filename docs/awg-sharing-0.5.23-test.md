# Неофициальная 0.5.23: обмен профилями AWG

Локальные тестовые сборки для Android ARM64 и Windows x64. Общий релиз 0.6.x и слияние в main этой работой не выполняются. Android сохраняет minSdk 27 (Android 8.1), targetSdk 36.

## Изменения

В «Подписки и профили» выбранным профилем AmneziaWG теперь можно поделиться через «Поделиться сервером» → «Буфер обмена» или «QR-код». Прежде кнопка была выключена: профили AWG хранятся как текст `.conf`, а обмен принимал только ссылки.

Экспорт формирует компактную ссылку `vpn://` в уже поддерживаемом Di-Tunnel формате Base64URL(qCompress(JSON)). Сохраняются полная клиентская конфигурация, имя сервера и явно указанная версия AWG. Повторный импорт использует существующие действия «Из буфера обмена» и сканирование QR-кода. Обмен работает через общую реализацию интерфейса в Android и Windows. Совместимость экспорта с другими VPN-клиентами отдельно не проверялась.

Ссылка содержит клиентский закрытый ключ, необходимый для подключения. Адрес подписки и сведения о её группе не добавляются в экспорт отдельного сервера. При превышении вместимости QR-кода диалог предлагает буфер обмена. Ошибки копирования не выдаются за успешное копирование; сообщение видно в окне обмена. После показа QR-кода кнопки копирования и отмены остаются доступны, в том числе в Windows.

## Проверки

- Core: 119 тестов пройдено. Проверены обратный импорт AWG 1.0/1.5/2.0/3.1, явно указанная версия, IPv4/IPv6, DNS, MTU, PSK, keepalive и параметры обфускации; повреждённые и слишком большие конфигурации не экспортируются.
- App: 113 тестов пройдено. Проверены доступность обмена в моделях Android и Windows, изменение выбранного профиля, распознавание готового PNG QR-кода с последующим импортом и переполнение вместимости QR-кода.
- Использованы только синтетические ключи, документационные адреса и домены. Подключение по экспортированному профилю требует ручной проверки на устройствах.

## Ручная проверка

1. Выбрать AWG и скопировать ссылку через «Поделиться сервером». Импортировать её в другом Di-Tunnel и сверить имя и версию AWG.
2. Показать QR-код в Windows и отсканировать его в Android. Повторить обмен в обратном направлении через буфер.
3. Проверить подключение по импортированному профилю и передачу данных. Для проверки можно использовать имеющийся AWG-профиль владельца; AWG на Android 8.1 у друга пока не проверен.

Восстановление после авиарежима и переключения Wi-Fi ↔ мобильная сеть, работа с выключенным экраном и AWG на Android 16 уже подтверждены владельцем для 0.5.22; подробности в [результатах диагностики](android-0.5.22-probe-diagnostics.md).
