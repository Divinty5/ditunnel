# Android 0.5.20: локальная проверка Android 8.1

Неофициальная тестовая сборка для проверки на Android 8.1 ARM64. Не опубликована и не подтверждает поддержку API 27 до испытаний на устройстве. Последний общий релиз Windows/Android остаётся 0.5.19. Переход всех платформ на 0.6.x выполняется отдельно после проверки.

## Изменения

- AndroidVersion: 0.5.20; versionCode: 50020. WindowsVersion и LinuxVersion не меняются.
- AndroidMinimumApiLevel: 27 в Directory.Build.props; оба Android-проекта используют это значение. Target API остаётся 36.
- scripts/Build-AndroidAwgBridge.ps1 использует тот же минимум для ARM64/x86_64 и сохраняет закреплённые версии Go, NDK и AWG. Локальный Build-AwgBridge.ps1 вызывает этот скрипт.
- Определение текущего процесса использует Application.ProcessName только с API 28; на API 27 читает /proc/self/cmdline с резервной проверкой через ActivityManager. Если имя недоступно, запуск завершается ошибкой, без смешивания Xray и AWG в одном процессе.
- Подзаголовок плитки обновляется только с API 29; на API 27 сохраняются название, значок и состояние плитки.
- Формат APK, applicationId, ключ подписи и зашифрованное хранилище профилей сохраняются. Штатное обновление с 0.5.19 возможно при совпадении сертификата.

## Сборка в подготовленной локальной среде

```powershell
& ./scripts/Build-AndroidAwgBridge.ps1
& ./.tools/android-build-local/Build-LocalApk.ps1 -Version 0.5.20 -VersionCode 50020
```

Локальные инструменты и подпись расположены в игнорируемой папке .tools/android-build-local. Скрипт нативной сборки принимает -EnvironmentRoot для другого размещения NDK и выходных библиотек. Для другого workflow DITUNNEL_ANDROID_AWG_ROOT должен указывать на созданную папку amneziawg/native, а управляемая сборка должна использовать то же значение AndroidMinimumApiLevel. APK: .tools/android-build-local/releases/0.5.20/Di-Tunnel-0.5.20-arm64.apk; контрольная сумма находится рядом.

## Проверка на телефоне

1. Дождаться полной загрузки APK и установить файл с расширением .apk. Файл .sha256 служит только для проверки целостности.
2. Открыть приложение, проверить версию 0.5.20, импортировать профиль и перезапустить приложение: профиль должен сохраниться.
3. Подключить используемый Xray-профиль, открыть сайты и проверить внешний IP. Если есть профиль AWG, повторить проверку с ним: мост AWG пересобран отдельно.
4. Отключить VPN, подключить снова и переключить сервер. Не должно быть зависания при повторном подключении.
5. При активном VPN переключить Wi-Fi и мобильную сеть, затем включить/выключить авиарежим. Проверить восстановление подключения и работу сайтов.
6. Выключить экран на 10–15 минут, разблокировать телефон и проверить соединение. Проверить отключение из уведомления, плитку и используемые виджеты.
7. Если используются правила приложений, проверить приложение внутри VPN и приложение-исключение.
8. Если используются Always-on и «Блокировать соединения без VPN», включить их после успешного ручного подключения. При потере соединения проверить блокировку трафика; после перезагрузки проверить восстановление. Эти функции нельзя считать проверенными только по появлению значка VPN.
9. По необходимости проверить QR-сканер, загрузку подписок по HTTPS и сохранение настроек.

При сбое записать действие, время, тип подключения (Xray/AWG), Wi-Fi/мобильная сеть и текст ошибки. Не передавать секретные ссылки профилей или ключи. Перед включением API 27 в общий релиз повторить основные сценарии на актуальном Android.

## Результаты

8 октября 2026 года локально собран и подписан Release ARM64 APK 0.5.20 (50020), minSdk 27, targetSdk 36. В итоговой компиляции нет предупреждений CA1416 о недоступных API; остаются прежние предупреждения nullable и устаревших Android API.

- apksigner verify: подписи v2/v3 корректны; сертификат совпадает с текущим ключом Android-релизов.
- aapt dump badging: версия, applicationId, minSdk/targetSdk и единственный ABI arm64-v8a проверены.
- zipalign -c -P 16 4: проверка пройдена.
- Проверены 114 ELF-библиотек из APK. У 11 есть отметка Android API: 10 собраны для API 21, AWG — для API 27. Остальные не содержат такой отметки; это не является доказательством совместимости каждого их вызова с API 27. SHA-256 встроенного AWG совпадает с результатом пересборки. Отдельно проверена отметка API 27 у x86_64 AWG для возможной проверки на эмуляторе.
- APK и SHA-256 для передачи: artifacts/android-0.5.20/; исходный результат и журналы проверок: .tools/android-build-local/releases/0.5.20/.

Проверка на физическом телефоне и эмуляторе не выполнялась. Установка, фоновая работа, восстановление, шифрованное хранилище и защита от обхода VPN пока не подтверждены. Эти результаты ожидаются от владельца до слияния в main.
