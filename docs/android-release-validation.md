## Автоматические проверки

- Release APK: application ID, versionName/versionCode, минимум API, ARM64, прежний сертификат и выравнивание 16 КиБ. Ключ и пароли вне Git.
- Проверочные входы требуют отдельные случайные RFC1929-данные. Реальный Android JSON проверен настоящим Xray на Windows/Linux: noauth/SOCKS4, неверные, соседние и прежние пароли отклонены; правильный запрос через синтетический VLESS проходит.
- Проверены запуск выключенного VPN двойным касанием выбранного профиля, сброс жеста при прокрутке, сохранение конкретного тайм-аута, отмена и обработка незавершённой проверки.
- Связь со службой `:probe` и сетевой путь Android проверяются на устройстве. Автоматические тесты покрывают обработку ввода и результатов, сборка APK проверяет метаданные и подпись.

## Текущее поведение

Для точной проверки профилей Xray временное ядро запускается отдельно для каждого профиля. Быстрый TCP-ответ показывает доступность узла, а успешный HTTPS-запрос подтверждает прохождение трафика через профиль. Карточка с сообщением «Проверка не завершена» сохраняется при удалении недоступных серверов. Подробности приведены в [описании протоколов и управления](android-controls-and-protocols.md).

В 0.6.18 виджеты берут активный профиль и подписку из состояния фактического туннеля. Оба размера получают один снимок состояния. Виджеты и плитка сверяются с процессом и системной VPN-сетью. Добавлены обновления при открытии шторки, изменениях сети и пробуждении, неточный таймер без пробуждения устройства. Ручное отключение не запускает восстановление; ограничения OEM не обходятся.
