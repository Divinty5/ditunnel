## Автоматические проверки

- Release APK: application ID, versionName/versionCode, минимум API, ARM64, прежний сертификат и выравнивание 16 КиБ. Ключ и пароли вне Git.
- Проверочные входы требуют отдельные случайные RFC1929-данные. Реальный Android JSON проверен настоящим Xray на Windows/Linux: noauth/SOCKS4, неверные, соседние и прежние пароли отклонены; правильный запрос через синтетический VLESS проходит.
- Проверены изоляция ошибок соседних профилей, разделение группы с сохранением паролей, отмена, короткие ошибки, квоты, уведомления и чистая политика сверки VPN-состояния.
- Desktop-тест не подменяет cross-UID прогон libXray на Android. ADB и системная сеть основной Windows агентом не использовались.

## Текущее поведение

До пяти обычных профилей используют один временный Xray с отдельными авторизованными входами и маршрутами. Точная проверка повторяет попытку при временном тайм-ауте. Быстрый TCP-ответ подтверждает доступность узла, а успешный HTTPS — прохождение запроса через профиль. Статус туннеля и состояние подписки проверяются отдельно.

Виджеты и плитка сверяются с процессом и системной VPN-сетью. Добавлены обновления при открытии шторки, изменениях сети и пробуждении, неточный таймер без пробуждения устройства. Ручное отключение не запускает восстановление; ограничения OEM не обходятся.

## Оставшаяся ручная матрица

По мере развития проверять clean install/обновление, API 27–36/OEM, длительный сон Huawei, смену сети/airplane mode, аварийное завершение процессов, Always-on/reboot/system lockdown, IPv6 и варианты AWG, QR/VMess, разделение, Lowest, обновление из GitHub и виджеты с закрытым UI. Текущий положительный прогон не означает выполнения всей матрицы.
