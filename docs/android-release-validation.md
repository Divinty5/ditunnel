# Проверка Android-релиза 0.4.24

Документ фиксирует состояние Android ARM64-сборки перед публикацией. Реальные подписки, ключи и необезличенные журналы в репозиторий не включаются.

## Матрица

| Среда | Результат |
| --- | --- |
| Android ARM64, телефон | Проверены запуск, импорт, VPN, переподключение, проверки профилей и QR-сканер |
| Huawei MatePad Pro, HarmonyOS 2 | Подтверждены установка, запуск и адаптация интерфейса после снижения `minSdk` до API 29 |
| Android x86_64 emulator | Используется для разработки и диагностики; не публикуется как релизный APK |

## Проверено вручную

- импорт HTTPS-подписки, отдельных VLESS/Shadowsocks/Hysteria 2 ссылок и QR-кода;
- выбор подписки без неявной смены VPN-профиля;
- явное переключение профиля при работающем VPN;
- быстрое и точное измерение задержки, включая Hysteria 2;
- потеря Wi-Fi/мобильной сети, немедленное обновление состояния и последующее восстановление;
- штатное отключение с закрытием Android VPN;
- адаптивный интерфейс телефона и планшета;
- DNS leak test: внешний VPN-IP и DNS Cloudflare в стране VPN-сервера, резолвер физической сети не обнаружен.

## Перед публикацией

1. Выполнить `dotnet test DiTunnel.sln`.
2. Опубликовать Release для `android-arm64`.
3. Проверить `versionName`, `versionCode`, `minSdkVersion=29`, ABI и APK Signature Scheme v3.
4. Выполнить clean install и обновление поверх предыдущей версии.
5. Повторить подключение, переключение, airplane mode, QR/import и DNS leak smoke-test.
6. Опубликовать SHA-256 рядом с APK.

## Ограничения

- Выпускается только `arm64-v8a` APK.
- Полная блокировка трафика вне VPN требует системных Always-on VPN и lockdown.
- Hysteria 2/QUIC чувствительнее к потерям UDP; проверка допускает повторную попытку и может занимать дольше TCP-профилей.
- OEM-ограничения фоновых служб могут потребовать разрешить приложению работу в фоне.
