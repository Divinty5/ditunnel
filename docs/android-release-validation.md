# Проверка Android ARM64

Актуализировано 5 октября 2026 года. Текущая локальная версия — 0.5.13 (versionCode 50013), синхронизирована с Windows; новая кнопка сброса требует проверки. В 0.5.12 пользователь подтвердил скачивание, установку, восстановление после потери сети и долгий тап плитки. APK подписан новым ключом этой линии. Отдельный GitHub-релиз 0.5.13 ещё не опубликован; доставка планируется штатным обновлением, без загрузки в Drive. Реальные ключи, профили, signing material и исходные NetLog в репозиторий не включаются.

## Подтверждено для AWG 2.0

- Импорт клиентского `vpn://`, запуск единственного Android VPN, подключение и VPN-выход.
- Быстрая проверка со свежим handshake и точная HTTPS-проверка.
- Работа Telegram/X и блокировка рекламы Hornet; при отключении блокировки реклама возвращалась.
- Автовыбор Vivaldi для проксирования и Mobifitness для обхода; внешний IP Vivaldi соответствует AWG-серверу.
- Корректное включение/отключение через плитку, синхронизация виджетов и выбранного сервера с приложением.
- Обновление новой линии тестовых APK до 0.5.9. Сайт chatgpt.com открылся через AWG, письмо отправилось.
- Повторный NetLog: два HTTP 200 через HTTP/2, девять TLS 1.3 соединений по IPv4, IPv6 отмечен недоступным и отсутствует прежний `ERR_CONNECTION_CLOSED`.

Подробности и ограничения: [проверка поддержки AWG](amneziawg-support-review.md). Эти результаты относятся к конкретному серверу и устройству; они не доказывают полную совместимость остальных вариантов AWG или отсутствие всех утечек.

## Автоматически и при сборке

- 98 Core, 83 Xray, 65 App и 46 Windows-тестов: 292 C#-теста; Go-suite AWG и go vet пройдены. TLS-тесты используют локальное доверие без загрузки цепочки из сети; отказ недоверенному сертификату проверяется отдельно.
- APK 0.5.10 собран локальным workflow; проверены versionName/versionCode, подпись тем же новым ключом, ARM64 и выравнивание.
- Runtime libXray/AWG и лицензии включены в APK, зависимости закреплены в eng и Go manifests.
- Локальные SDK/NDK, workflow, ключ и пароли, APK и диагностические журналы исключены из Git. Пользователь проверил распаковку зашифрованной резервной копии ключа.

## Историческая проверка 0.4.24

На телефоне подтверждались Xray-подписки, VLESS/SS/Hysteria 2, QR, переключение сервера, потеря и восстановление Wi-Fi/мобильной сети, UI и DNS leak test с DNS Cloudflare в стране VPN-сервера. Эти результаты сохраняются как история; они не заменяют полный прогон текущей 0.5.13 и нового AWG backend.

## Перед публичным выпуском

1. Повторить clean install и обновление новой линии APK; проверить versionName/versionCode, minSdk 29, arm64 ABI, подпись и zipalign. APK со старой утраченной подписью не обновляется новым ключом без удаления приложения и локальных данных.
2. Проверить Android API 29–36, OEM background restrictions, планшет и длительную работу без Mono/native crash.
3. Проверить AWG 1/1.5/2/3/3.1 на совпадающих серверах, реальный IPv6 endpoint и внутренний IPv6. Выбор пригодного семейства handshake и DNS исправлен и покрыт регрессионными тестами; необходим прогон на реальном IPv6-сервере.
4. Повторить оба режима проверки при активном/отключённом VPN, Lowest, смену подписки, отмену подключения/переподключения и проверки.
5. Проверить все режимы маршрутизации, доменные правила, реальный обход приложений, DNS/IPv6-утечки, потерю сети, сон, airplane mode, смену сети и аварийное завершение служебных процессов.
6. Повторить QR/import и VMess на устройстве, все четыре языка, плитку и пять размеров виджетов с закрытым приложением.
7. Проверить новое сервисное восстановление без UI, Always-on, системный lockdown и запуск после reboot по [ручному сценарию](awg-manual-validation.md).
8. Опубликовать APK и SHA-256 только после завершения матрицы; проверки GitHub-обновлений проводить отдельно для каждой платформы.

## Ограничения

Актуальный APK для повторной проверки — Android 0.5.13. В 0.5.10 возврат мобильной сети с HY2 оставлял бесконечное восстановление. В 0.5.11 добавлен явный foreground-контроллер; в 0.5.12 пользователь подтвердил исправление на Xiaomi и открытие приложения долгим тапом. Проверить новую кнопку сброса, штатное обновление, расширенную матрицу восстановления и системный Always-on по [новому сценарию](controls-recovery-validation.md).

- Публичный формат Android — только ARM64 APK; Google Play Services не требуются.
- В Android 0.5.10 включена поддержка системного Always-on VPN. Сервис использует Sticky и восстанавливает последнюю конфигурацию из хранилища, зашифрованного Android Keystore, без зависимости от открытого интерфейса. Перезапуск после потери служебного процесса и смены сети реализован; автозапуск после перезагрузки требует включённого системного Always-on. Блокировку трафика во время восстановления обеспечивает системная настройка «Блокировать соединения без VPN», а не Sticky. Возврат после потери сети подтверждён в Android 0.5.12; reboot, lockdown и расширенные сценарии без UI требуют проверки на телефоне: [порядок ручной проверки](awg-manual-validation.md).
- AWG допускает один Peer и готовую клиентскую конфигурацию. Handshake не подтверждает доступность всех сайтов; DNS и HTTPS-контроль должны попадать в AllowedIPs.
- Hysteria 2 и внешний AWG UDP зависят от качества сети; OEM может ограничивать фоновые процессы.
