# Di-Tunnel 0.6.2 — Windows, Android и Linux

Версии трёх платформ синхронизированы: 0.6.2; Android versionCode — 60002. Минимальная версия Android — API 27 (Android 8.1).

- В разделе «Соединение» появился переключатель «Использовать только IPv4», включённый по умолчанию, в том числе при обновлении старых настроек. VPN использует IPv4 DNS, подавляет ответы AAAA и блокирует IPv6 внутри туннеля. Выключение переключателя возвращает поддержку IPv6, если она предусмотрена профилем. Изменение применяется при переподключении.
- Разделы настроек сворачиваются и при каждом открытии страницы начинают свёрнутыми. Сворачивание сохраняет редактируемые значения; смена языка сохраняет раскрытые разделы текущего посещения.
- Исправлено подключение Windows с исключениями, содержащими только доменные зоны `ru` и `рф`.
- На Android убрано ошибочное сообщение о встроенном kill switch во время подключения.
- При смене темы Windows заголовок перерисовывается сразу. Для X11 Linux передаётся актуальная подсказка `_GTK_THEME_VARIANT`; оформление зависит от поддержки оконным менеджером.
- При возврате Windows из трея восстанавливаются точные внешние размеры и положение окна, включая расположение у края экрана.
- Обновление цвета полного значка Windows больше не удаляет и не добавляет заново кнопку панели задач. Значки окна, трея и ярлыков используют те же цвета, что и кнопка VPN. Для цветов используются отдельные ICO и стабильный AppUserModelID. Автоматическая проверка подтверждает цвета нативного значка окна и ресурсов ярлыков; немедленное обновление закреплённой кнопки Explorer требует ручной проверки.

Имена пакетов для автообновления:

| Платформа | Пакет |
| --- | --- |
| Windows x64 | `Di-Tunnel-0.6.2-Setup-x64.exe` |
| Android ARM64 | `Di-Tunnel-0.6.2-arm64.apk` |
| Linux amd64 | `Di-Tunnel-0.6.2-linux-amd64.deb` |

Каждый пакет сопровождается одноимённым файлом `.sha256`. Этот документ описывает подготовленную сборку; публикация стабильного релиза выполняется отдельно после проверки.

Ограничение режима IPv4: сайты, доступные только по IPv6, при включённом переключателе недоступны. Браузерный защищённый DNS может получать AAAA через HTTPS, но IPv6-соединения внутри VPN всё равно блокируются. Режим не исправляет маршрутизацию VPS; для сравнения качества связи следует проверить те же сайты с включённым и выключенным переключателем после переподключения.
