# Di-Tunnel 0.6.3 — Windows, Android и Linux

Исторические заметки о промежуточной тестовой сборке. При ручной проверке обнаружены исчезновение кнопки и отсутствие обновления закреплённого значка; описанные ниже проверки HICON/ярлыков этого не выявляли. Окончательное исправление включено в [0.6.4](release-0.6.4.md).

Версии трёх платформ синхронизированы: 0.6.3; Android versionCode — 60003. Минимальная версия Android — API 27 (Android 8.1).

- При смене состояния VPN в Windows обновлены нативный значок окна, ресурсы собственных ярлыков, в том числе закреплённых, и регистрация кнопки панели задач Explorer. Цвет соответствует кнопке VPN: фиолетовый, зелёный или красный. Обновление выполняется без сворачивания окна; сохраняются AppUserModelID, положение и размеры окна. При повторном создании кнопки Explorer повторно передаётся текущий ресурс без рекурсивной перерегистрации.
- На всех платформах убраны рамки и фон заголовков и содержимого разделов настроек. Стрелки сворачивания расположены рядом с названиями; длинные названия переносятся на узких экранах. Сохранены сворачивание, редактируемые значения и управление заголовками с клавиатуры.

Имена пакетов для автообновления:

| Платформа | Пакет |
| --- | --- |
| Windows x64 | `Di-Tunnel-0.6.3-Setup-x64.exe` |
| Android ARM64 | `Di-Tunnel-0.6.3-arm64.apk` |
| Linux amd64 | `Di-Tunnel-0.6.3-linux-amd64.deb` |

Каждый пакет сопровождается одноимённым файлом `.sha256`. Публикация стабильного релиза выполняется отдельно. Автоматическая проверка значков использует временные ярлыки и синтетические состояния VPN, без подключения к сети; внешний вид закреплённой кнопки конкретной версии Explorer требует ручной проверки.

Проверены 125 тестов приложения. UI smoke подтвердил раскрытие разделов, управление пробелом, сохранение черновиков и размещение стрелок на ширине 360 и 900 в светлой и тёмной теме. Windows smoke подтвердил цвета нативных значков и ресурсов ярлыков, восстановление исходных ярлыков и сохранение размеров, видимости, фокуса и AppUserModelID при перерегистрации видимой кнопки отдельного тестового окна. Пользовательские закрепления и сетевые настройки в этих проверках не изменялись.

Release-сборки Windows и Linux выполнены на Windows без ошибок и предупреждений; Android ARM64 — без ошибок, с 32 предупреждениями в существующем коде Android. В сгенерированном Android-манифесте подтверждены versionName 0.6.3 и versionCode 60003. Запуск на Android и Linux и публикация установочных пакетов в эти проверки не входили.
