# Di-Tunnel 0.6.18

Общий выпуск для Windows x64, Android ARM64 и Ubuntu 24.04 amd64. Изменения накоплены с публичного выпуска 0.6.13.

## Изменения

- Один щелчок или касание выбирает профиль для действий. Двойное или долгое нажатие подключает VPN через этот профиль либо переключает активный туннель.
- Добавлены жёлтые состояния подключения, восстановления и проверки. Активный профиль выделяется отдельно от выбранного. Кнопки проверки и отмены сохраняют своё место даже в списке с одним профилем.
- Добавлено прямое обновление подписок через физическую сеть. Подписка со ссылкой сохраняется при удалении последнего сервера. Удаление одиночного ручного сервера требует подтверждения, в том числе через «Недоступные».
- На Android уточнены точные HTTPS-проверки и причины неудачного запуска VPN. Результат запуска, в том числе тайм-аут AWG handshake, отображается в карточке профиля. Виджеты показывают профиль фактического подключения и обновляют статус из общего состояния туннеля.
- Для Ubuntu добавлен графический установщик `.run`. Приложение сверяет установленную версию пакета перед перезапуском после обновления.
- Исправлены имена импортированных профилей AmneziaWG и Hysteria 2 и уточнён автовыбор приложений.
