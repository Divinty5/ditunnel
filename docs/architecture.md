# Архитектура Di-Tunnel

Общий интерфейс Avalonia находится в `src/DiTunnel.App`, модели профилей, политики проверок и диагностические поля — в `src/DiTunnel.Core`. `DiTunnel.Infrastructure.Xray` готовит конфигурации Xray и выполняет проверки. Платформенные модули предоставляют сетевой доступ, управление VPN, обновления и защищённое хранение. [Решение об интеграции Xray](adr/0001-xray-runtime.md).

| Платформа | Сетевой слой |
| --- | --- |
| Windows | Интерфейс с обычными правами вызывает отдельный C#-модуль `Di-Tunnel.NetworkHost.exe` для Wintun, маршрутов, DNS/NRPT и WFP. PowerShell используется в разработке, при подготовке пакетов и в ручном скрипте восстановления. |
| Android | `VpnService` создаёт VPN-интерфейс и задаёт DNS через Android API. Отдельные процессы обслуживают туннель и проверки. Foreground-контроллер отслеживает физическую сеть и перезапускает нативный процесс при восстановлении. |
| Linux | Системная служба с разрешением polkit управляет TUN, маршрутами, DNS через systemd-resolved и защитой nftables. GUI и служба обновляются вместе. |

Подключение AmneziaWG использует закреплённое Go-ядро и сетевой стек в памяти. Xray обслуживает системный интерфейс, доменные правила и фильтрацию. Семейства маршрутов и DNS зависят от Address, AllowedIPs, платформы и профиля. [Интеграция AWG](amneziawg-integration.md) · [Windows WFP](adr/0002-windows-kill-switch.md) · [Границы Linux](adr/0003-linux-platform-boundaries.md).

Точная проверка Xray на Android запускает временное ядро для каждого проверяемого профиля. На Windows быстрые проверки работают с ограниченным параллелизмом, а при активном kill switch общий слот временного разрешения WFP используется последовательно. Для диагноза важны фактический этап, тип ошибки и контекст текущей попытки. [Android](android-controls-and-protocols.md) · [Windows](windows-tun-validation.md) · [Linux](linux-vpn-stage.md).

## Профили, подписки и состояние подключения

Страницы настроек и подписок находятся в `SettingsPage` и `SubscriptionsPage`. `MainViewModel` предоставляет привязки и команды интерфейса. Выбранный профиль определяет, с какой карточкой работает пользователь. Подключаемый профиль относится к текущей попытке, а активный соответствует профилю VPN-сессии. При просмотре другой подписки активный туннель продолжает работать.

- `ProfileCatalog` хранит группы, библиотеку и видимые карточки. Идентичность профиля определяется парой `SourceId` и `Content`. При обновлении текущей группы каталог переиспользует карточки для неизменившихся профилей. Широкая сетка и список приложений раздельного туннелирования создают элементы по мере прокрутки.
- `SubscriptionRefresh` загружает источники параллельно с ограничением на число запросов. Перед применением он сверяет каждый источник с состоянием на момент начала обновления. Подходящие изменения записываются одним сохранением библиотеки через платформенное хранилище. При ошибке загрузки или сохранения прежние профили остаются доступны.
- `ProfileProbeCoordinator` организует поштучные, пакетные и потоковые проверки. `ProfileProbeHistory` хранит результаты по профилям и восстанавливает состояние карточек при смене группы. Результат текущей операции и история выбранного профиля имеют собственный контекст. Общий формат отчёта задают `ProbePolicy` и `ProbeDiagnostics`.
- `ActiveTunnelMonitor` ведёт проверки работающего VPN и определяет условия перезапуска либо перехода на запасной профиль. `LowestProfileMonitor` планирует периодический поиск подходящих серверов и ранжирует кандидатов. Переключение и восстановление соединения выполняются через платформенный VPN-движок.

## Интерфейс и сторонние данные

Карта построена на береговых линиях Natural Earth 1:110m из общественного достояния. Материки и точки используют общий SVG viewport. Воспроизводимый генератор находится в [Generate-WorldMap.py](../scripts/Generate-WorldMap.py). [Natural Earth](https://www.naturalearthdata.com/).

Компонент Windows для панели задач использует MinHook 1.3.4 и кэш публичных символов Microsoft. При несовместимости символов перехват не включается. Для ExplorerPatcher используются экспорты его модуля. [Устройство значка панели задач](windows-taskbar-icon-investigation.md).

Версии и контрольные суммы нативных зависимостей закреплены в [eng](../eng). Windows включает Xray-core и Wintun, Android — libXray, Linux — Xray-core с патчем поиска процессов. Ядро AmneziaWG собирается с закреплёнными Go-зависимостями. Лицензии и уведомления сторонних компонентов входят в пакеты.
