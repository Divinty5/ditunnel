# Пакет Linux 0.6.6

Сборка предназначена для Ubuntu 24.04 amd64. Версии Windows 0.6.5 и Android 0.6.4 не повышаются.

Для публикации отдельного Linux-релиза используется обычный числовой тег `v0.6.6`, например с названием «Di-Tunnel 0.6.6 — Linux». Обязательные файлы:

- `Di-Tunnel-0.6.6-linux-amd64.deb`
- `Di-Tunnel-0.6.6-linux-amd64.deb.sha256`

Тег с префиксом платформы, например `linux-v0.6.6`, текущий клиент не распознаёт как номер версии. Имя пакета должно соответствовать номеру тега. Черновики и prerelease автообновлением пропускаются.

`ReleaseChecker` просматривает список опубликованных стабильных релизов, а не только глобальный GitHub latest. Каждый клиент выбирает максимальную версию с установочным файлом и SHA-256 именно своей платформы. Если в 0.6.6 есть только deb, Windows и Android пропускают этот релиз без ошибки и продолжают искать совместимый пакет в других релизах. Неполная загрузка, при которой ещё нет SHA-256, тоже не вызывает предложение обновления.

Это поведение присутствует в исходниках общего релиза 0.6.4. Добавлены регрессии: Linux-only 0.6.6 не скрывает предыдущий Windows/Android-пакет и не предлагает обновление уже актуальному клиенту.

Исправления: автоматическое переключение с сохранением KS, проверки других серверов при KS, повторное подключение после сбоя ядра, разрешение polkit на время работы конкретного активного GUI, локальное определение страны и подпись метода проверки рядом с задержкой. Последнее изменение находится в общем интерфейсе и войдёт также в следующую сборку Windows.

Установка: [инструкция](linux-installation.md). Результаты проверки пакета: [Ubuntu VM](linux-0.6.6-validation.md).
