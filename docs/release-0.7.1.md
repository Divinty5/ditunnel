# Di-Tunnel 0.7.1 — проверка на устройствах

Пакеты **0.7.1** подготовлены для проверки на устройствах. Android использует `versionCode 70001` и прежний релизный сертификат. [Установка и обновление](installation.md).

| Платформа | Сжатый пакет | Размер локальной сборки |
| --- | --- | ---: |
| Windows x64 | `Di-Tunnel-0.7.1-Setup-x64.exe` | 57,07 МиБ |
| Android ARM64, API 27 и выше | `Di-Tunnel-0.7.1-arm64.apk` | 44,45 МиБ |
| Ubuntu 24.04 amd64 | `Di-Tunnel-0.7.1-linux-amd64.deb` | 47,79 МиБ |
| Ubuntu 24.04 amd64, графическая установка | `Di-Tunnel-0.7.1-linux-amd64.run` | 47,80 МиБ |

У каждого пакета есть отдельный `.sha256`. Автообновление предложит 0.7.1 после публикации установщика Windows, релизного APK или `.deb` вместе с соответствующей контрольной суммой в стабильном выпуске `v0.7.1`. [Файлы для автообновления](build-and-release.md#файлы-для-автообновления).

Пользователь подтвердил установку и работу сжатых сборок Windows и Android. Для Linux локально проверены версия приложения, `.deb` и встроенный пакет `.run`. Установка Linux на устройстве и обновление из опубликованного выпуска остаются сценариями проверки.

## Сценарии проверки

1. Установите пакет поверх предыдущей версии. Проверьте номер версии в приложении, наличие подписок и ручных профилей, сохранение выбранного сервера и настроек раздельного туннелирования.
2. Запустите обновление подписок. Откройте большую группу, прокрутите список, смените группу и выполните сортировку по результатам проверки. На Android проверьте узкую и широкую раскладки, поворот экрана и возврат из фона.
3. Подключитесь к рабочему профилю и выберите другую карточку. Проверьте, что активный сервер остаётся прежним до явного переключения. Затем переключите профиль, запустите проверку нескольких серверов и отмените её. Сверьте уведомление с копируемой диагностикой.
4. При активном VPN откройте подписки или настройки, затем вернитесь к карте. Проверьте положение и плавность огоньков. Повторите после сворачивания окна или возврата из фона.
