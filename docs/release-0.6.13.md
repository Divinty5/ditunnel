# Di-Tunnel 0.6.13 для Windows, Android и Linux

- На Windows и Linux регулярная HTTPS-проверка идёт через действующий TUN. Одиночный тайм-аут оставляет VPN активным и меняет цвет кнопки на фиолетовый. После двух последовательных транспортных сбоев Di-Tunnel переподключается к тому же серверу. Если это не помогает, Lowest может выбрать проверенный сервер из той же подписки.
- Можно обновить только выбранную подписку. После фильтрации или удаления последнего профиля пустая подписка сохраняется. Вернувшиеся профили отображаются как непроверенные.
- Добавлена поддержка Salamander для Hysteria 2. Проверка сертификата TLS обязательна.
- На Android исправлена сборка с закреплённым libXray. Результаты массовой проверки отображаются по мере готовности.
- Установщик Windows закрывает запущенный Di-Tunnel при обновлении. Фоновое обновление подписок при старте оставляет кнопку подключения доступной.

[Скачать 0.6.13](https://github.com/Divinty5/ditunnel/releases/tag/v0.6.13). Доступны установщик Windows x64, подписанный APK для Android ARM64 (Android 8.1+, versionCode 60013), пакет для Ubuntu 24.04 amd64 и контрольные суммы SHA-256.
