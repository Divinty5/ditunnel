# Security policy

Di-Tunnel handles network traffic and credentials, so security reports should not be disclosed in a public issue.

Please use GitHub's private vulnerability reporting for this repository. Include affected versions, reproduction steps, impact and any suggested remediation. Do not include real VPN credentials unless they are strictly necessary; use newly generated test credentials and revoke them after the report.

During the planning phase there are no supported releases. A supported-version table and response targets will be added before the first release.
