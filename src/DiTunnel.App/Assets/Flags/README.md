Flag artwork: https://github.com/hampusborgos/country-flags (Wikimedia Commons/public-domain national flags; see upstream README).

Rasterized from the two-letter country SVGs to 100 px wide PNGs using Sharp. Upstream archive retrieved 2026-09-06, SHA-256: `1780ad98c95d9436620967d4ab3e88919efd0a0deba8e773d2eeb0d4f5c5fd88`.

The application bundles these images. Country lookup uses the local `Runtime/geoip.dat` from the pinned Xray distribution; no online IP geolocation API is used.
